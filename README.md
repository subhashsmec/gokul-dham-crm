# Gokul Dham CRM — Free Android-first Edition

## Zero-cost use
This is an offline-first Progressive Web App (PWA). It stores CRM data in the phone/browser's IndexedDB/localStorage-compatible storage and can be installed from Chrome as an app.

## Quick install on Android
1. Put this folder on any HTTPS static host OR run it from a local development server.
2. Open the site in Chrome on Android.
3. Chrome menu -> Add to Home screen / Install app.
4. Open Gokul Dham CRM from the new icon.
5. Use Reports -> Download Backup JSON regularly.

For a truly zero-cost personal setup, you can host the static files on a free static-hosting service. Do not expose an unprotected local server to the public internet.

## Included
- Dashboard
- Resale property inventory
- Supplied Gokul Dham map
- Lead CRM
- Call/WhatsApp shortcuts
- Follow-ups

## Important
This version does NOT claim automatic Facebook lead ingestion or paid AI API access. Those require external permissions/services. The app creates drafts from the data you enter.
